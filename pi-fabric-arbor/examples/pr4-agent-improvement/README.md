# PR4 exact-material agent fixture

`baseline.md`, `candidate.md` and `tasks.json` are packaged inputs for Arbor's deterministic native installation gate. The fake model interprets the two marker instructions; the product independently grades the returned answers. This proves snapshot loading and grading, not real-model quality.

The native test copies these installed assets into a disposable Git repository, records the two full commit OIDs and freezes the evaluation definition before calling the actual installed Arbor owner/evaluator. That test preparation does not dispatch or grade in place of the product. No profile skill, paid inference or dataset is needed.

For an existing material pair, use owning-Pi `/arbor start` overrides with `execution: "evaluate"`, `evaluator.kind: "agent-suite"`, and `evaluator.definition` set to a closed definition path. `definitionSchema()` is exported by the package and included in the action manifest. Select an available exact subject model. The native gate supplies local fake inference explicitly; no fake runtime is shipped as product code.

`preset.json` supplies closed defaults below profile/project/explicit overrides. It cannot launch anything. These assets have no preparation CLI or executable plugin. The product CLI/browser remain read-only. Dirty capture, candidate generation and scaffold workflows belong to later PRs.
