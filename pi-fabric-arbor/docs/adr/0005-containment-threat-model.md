# ADR 0005: Containment threat model and non-interference

Status: Accepted for local Phase 3 B5/B6 evidence

## Protected assets

The active checkout, Git common directory, sibling worktrees, user refs, index, stash, tracked and untracked bytes, credentials, agents, sockets, devices, evaluator inputs, held-out data, and unrelated environment remain outside worker authority.

## Decision

The Linux production seam uses `LinuxBubblewrapContainmentAdapter` and fails closed unless active prerequisites match policy. Every run receives fresh user, PID, IPC, UTS, cgroup, network, and mount namespaces, an empty root, a package workspace as the only writable host bind, bounded tmpfs scratch, a minimal device set, one allowlisted executable with its dynamic-library closure, and a scrubbed environment. Timeout, cancellation, oversize, and abnormal completion terminate the namespace-owning process group.

Before the contained target can execute, the adapter gates Bubblewrap with `--block-fd 0`. It accepts Bubblewrap's JSON status, verifies namespace isolation and exact cgroup membership and limits while the child is guaranteed to remain alive, constructs the certain containment identity, and only then releases the gate. Resource-control unit names combine a recognizable containment-ID prefix with a digest of the canonical authority `stateRoot` and full containment ID, preventing cross-authority collisions while preserving journal correlation.

The retained B5 certificate is Ed25519-signed and valid only when all 34 named adversarial checks are direct and passing. Startup verification compares platform, Node, Bubblewrap version/binary digest, and exact compiled adapter digest to active inputs.

Production workspace, Fabric-child, evaluator, report, and cleanup seams have `FingerprintBoundaryGuard` decorators. Before/after manifests are generated by two separately implemented walkers and orchestration paths. Captures include source and sibling identities, status v2, index bytes/metadata/extensions, tracked/untracked bytes and metadata including link counts, HEAD, refs/reflogs/stash, packed refs, worktree registration, Git common-directory inventory, mount identity, and exact tool digests. Certificates bind run/effect/command/correlation/fence/revision/containment/package/report identities, require exact equality, are Ed25519-signed, chain to a predecessor, and quarantine on mismatch or uncertainty.

## Evidence and limits

- `certification/containment/linux-x86_64-bwrap-0.12.0/`
- `certification/fingerprint/linux-git-2.55.0/`
- `tests/containment/bubblewrap.test.ts`
- `tests/git/fingerprint.test.ts`

B5 is platform-local. Package-install testing covers denied package-manager execution, not arbitrary user-space file copying. Embedded public keys prove artifact integrity, while deployment trust anchoring remains an operator responsibility. Unsupported or changed inputs require recertification and otherwise block startup.

## Consequences

A clean Git status is never sufficient evidence. Capture ambiguity, oracle disagreement, containment identity ambiguity, or certificate mismatch is terminal for the boundary. This closes local B5/B6 evidence without claiming B1. B7 and B8 are separately certified against their own active authorization and held-out inputs.
