# Research workflow revision acceptance

## Intent and baseline
Manual /skill:fabric-research remains the entry point. Substantive research builds a code-held workflow; Main frames and orchestrates, workers discover, research, independently verify, repair, synthesize and validate. Keep readable evidence notes and report depth. Narrow fact lookup may remain direct. Never silently switch substantive research to Main when delegation fails.

Observed baseline: runs/research-architecture-decision-tools-1788797692774 plus session 01a07ca2-89a4-7193-a7c4-a4d2a1df7182. Four successful research spawns; Main fetched primary sources (entry 52), extracted candidates (67), verified shortlist (178), closed verification ledger (217), and session compacted (223). Current skill explicitly requires Main verification/full stream reads/direct repair/synthesis. Historical trace is the real failure baseline, not a controlled timing comparison.

## Criteria
C1: Main frames/builds/runs one workflow program, without routine substantive retrieval, full stream reads, gap repair or report writing.
C2: Program owns planning -> parallel research -> independent verification -> bounded gap repair/reverification -> synthesis -> report validation; dependencies stay in code.
C3: Evidence remains substantive in owned Markdown, with source support, actual results, counterevidence and uncertainty. Compact outputs contain control/navigation, not evidence dumps.
C4: Unique path ownership and durable launch accounting; preserve partial artifacts, no duplicate launches on interruption, no rerun of successful siblings.
C5: Unavailable model/tool, exhausted allowance, or failed verification returns blocked/partial; no silent Main research fallback.
C6: Narrow lookup and no-write branches remain honest and respect scope; substantive no-write work stays delegated with no false saved paths.
C7: Exact manual registration, valid frontmatter, resolvable references; no stale Main-owned research rules across references including last30days.

## Evaluation plan
Static validator, ownership/link assertions, fresh-context behavior probes, and a bounded fixture-backed workflow execution if native recursion is available. Preserve the original run. No claim that static checks or one smoke run prove absence of future compaction. No broad web research rerun or live package changes.
