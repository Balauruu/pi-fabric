- C2: No packet generations, mandatory evidence JSON, candidate/review/synthesis copies or custom persistence framework remain in the active skill.
- C3: Workers save substantive notes incrementally with actual source passages, results, methods, qualifications and counterevidence; compact handoffs point to those notes rather than replacing them.
- C4: Main reads full relevant research sections and verifies decisive support; metadata, design-only study descriptions and worker success cannot satisfy research adequacy.
- C5: Completed or partial substantive work produces a readable REPORT.md with source citations, links to local notes, explicit coverage/gaps and the actual stop reason.
- C6: Browser/provider/profile restrictions, explicit worker model, tool grants, exact counts, partial-result preservation and ambiguous-launch recovery remain intact.
- C7: Explicit `/skill:fabric-research` registration remains intact. All active support links resolve; removed schema has no live consumers.
- C8: Direct, delegated and blocked/read-only boundary behavior is probed in fresh contexts. Static checks are distinguished from live retrieval and subjective depth evaluation.
- C9: Existing research and unrelated uncommitted files are untouched. Optional last30days output is scoped within the dossier without recreating the default packet pipeline.
