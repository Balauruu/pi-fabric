Score only observable gaps: unowned requirements; thin decisions; detached evidence; weak phase gates or handoff; incomplete unit packets; stale dependency-derived waves/modes or ordering projection; generic File Impact instead of Before/After deltas; stale guarded source snippets or illustrative code presented as current source; weak Key metrics; missing path, test, verification, or fallback; unresolved blockers; ungrounded approach options; and cross-layer risk.

Repair Before/After bodies, the single global Key metrics overview, ordinals, symbols/type labels, permalinks, phase owner/detail ledgers, and observability inventory; revalidate affected guarded snippets.
